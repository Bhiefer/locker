# Otevřené otázky

Tyto body nejsou závazně rozhodnuté. Agent je nesmí vyplnit vlastním odhadem, pokud jsou podstatné pro úlohu.

1. Přesný rozsah oprávnění šestimístného servisního PINu.
2. Přesný formát MQTT JSON událostí a potvrzení příkazů.
3. Zda bude použit transakční outbox pro MQTT.
4. Přesný WooCommerce webhook a stav objednávky, při kterém se rezervuje box.
5. Chování při quantity vyšší než počet dostupných boxů.
6. Zda je dovoleno částečné přidělení objednávky.
7. Přesný postup po třech dnech a pravidlo fyzického uvolnění boxu.
8. Zda bude existovat bezpečný offline výdej při nedostupném middleware.
9. Přesná pravidla rotace a správy servisního PINu.
10. Zda Home Assistant smí pouze číst, nebo také vyvolávat servisní akce.
11. Aktuální databázové schéma a existence produkčních dat.
12. Přesný mechanismus autentizace mezi WooCommerce, middleware a MQTT brokerem.
